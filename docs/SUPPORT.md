# Reporting a problem

Open a GitHub issue with:

- Chonko version, macOS version and Mac model.
- Selected media type, compression settings and save mode.
- What happened, what you expected, and whether Stop worked.
- The exported JSON from Diagnostics → Export Report.

Do not post private images, documents, videos or screenshots containing sensitive information. A synthetic or public sample that reproduces the issue is helpful. Diagnostics stay local until you choose to export and share them.
